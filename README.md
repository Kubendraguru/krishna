# Distill — "Built for people. Read by machines."

A comparison hero built with **Vite + React**.

## Features

- **Top Nav & Hero Copy:** 56px navbar with custom SVG droplet and links; two-column hero copy with Newsreader serif typography and interactive pill buttons.
- **Continuous Conveyor Belt:** Smooth infinite conveyor drifting left with modulo-based card loop.
- **Interactive Scrubbing:** Pointer capture dragging with inertia, horizontal wheel/trackpad support, and hover slowdown.
- **Glowing Scanner & Dynamic Counter:** Center scanner line with halo and real-time token reduction countdown.
- **Canvas Particle Dissolve:** 2D Canvas drawing orange haze, dithered surface particles using a 32-bit integer hash, and ember sparks.
- **Twin Code Layer:** Reveals distilled HTML source with comment headers and smooth mask fade-out on the left.
- **Responsive & Accessible:** Adapts to mobile screens (`≤ 767px`) and respects `prefers-reduced-motion`.

## Getting Started

```bash
# Install dependencies (already installed)
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
